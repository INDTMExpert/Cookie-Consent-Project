# 🚀 Funny Consent Modal Project

A fun and interactive JavaScript modal project that simulates a fake “data consent” popup with humorous UI interactions and animations. This project demonstrates the use of **HTML**, **CSS**, and **JavaScript DOM manipulation** in a creative way.

---

# 📸 Preview

This project includes:

- A delayed popup modal
- Interactive hover effects
- Form handling with JavaScript
- Fake loading animation
- Dynamic content updates
- Funny prank-style user interaction

---

# 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

---

# ✨ Features

## ⏳ Delayed Modal Popup
The modal automatically appears after **1.5 seconds** using `setTimeout()`.

## ❌ Close Button Control
The close button stays disabled until the fake process is complete.

## 🎭 Funny Hover Effect
When the user tries hovering over the **Decline** button, the buttons switch positions using Flexbox.

## 📄 Form Submission Handling
Uses:

- `preventDefault()`
- `FormData()`
- Dynamic DOM updates

## 🔄 Fake Loading Animation
Displays a fake “Uploading your data to the dark web...” loading screen.

## 😆 Dynamic Success Message
After submission, the modal changes into a funny prank confirmation screen.
